# 小说创作辅助软件 — 需求分析报告（粗略版）

## 一、项目概述

### 1.1 项目背景

面向网文作者/小说创作者的辅助工具，解决三个核心痛点：

- **拆书难**：几百万字的小说人工分析耗时耗力，难以快速提取情节结构、人物关系、爽点节奏。
- **写作工具弱**：通用文本编辑器缺少小说创作专用功能（大纲、人物卡、伏笔管理）。
- **创作孤岛**：写作、分析、素材管理分离，缺乏一体化辅助。

### 1.2 项目目标

构建一个 Web 端小说创作辅助平台，实现 **拆书分析 + 在线编辑 + AI辅助创作** 三位一体。

### 1.3 技术选型

| 层级     | 技术                                                         |
| :------- | :----------------------------------------------------------- |
| 后端     | Spring Boot 3.x + MyBatis-Plus + Spring Security + JWT       |
| 前端     | Vue 3 + Vite + Pinia + Element Plus + WangEditor/ProseMirror |
| 数据库   | MySQL 8.0 + Redis（缓存/会话）                               |
| 文件存储 | 本地/MinIO（大文件、导出文件）                               |
| AI能力   | 对接大模型API（OpenAI/DeepSeek/通义等）或本地模型            |
| 异步任务 | Spring Async / RabbitMQ（大文件解析）                        |
| 部署     | Nginx + Docker                                               |

## 二、功能需求

### 模块一：小说拆书分析模块

#### 1.1 文件上传与解析

- 支持格式：`.txt` / `.epub` / `.docx`，单文件上限 50MB（约几百万字）
- 自动识别章节（正则匹配"第X章"等规则，支持自定义规则）
- 大文件异步解析，进度条反馈
- 存储：原文分章入库 + 原文文件存 MinIO

#### 1.2 章节结构化

- 章节列表（标题、字数、序号）
- 章节正文分页加载（避免几百万字一次性渲染）
- 自动分卷识别（"第X卷"）

#### 1.3 情节分析（核心）

- **章节摘要**：AI 逐章生成 100 字摘要
- **情节曲线**：按章节统计冲突强度/情绪值，绘制折线图
- **爽点/钩子识别**：标记高潮、悬念、反转位置
- **节奏分析**：统计对话/描写/叙述占比
- **人物出场统计**：基于 NER 或规则提取人名，统计出场频次与章节分布
- **人物关系图**：基于共现关系生成关系网络图（ECharts Graph）
- **关键词/主题提取**：TF-IDF / TextRank
- **情节线梳理**：主线/支线识别（进阶，可后续迭代）

#### 1.4 分析报告

- 生成可视化报告页（图表 + 结论）
- 支持导出 PDF / Markdown
- 分析结果缓存，避免重复调用 AI

------

### 模块二：小说编辑模块

#### 2.1 作品管理

- 作品 CRUD（书名、简介、封面、分类、状态）
- 多作品切换
- 卷/章树形目录管理（拖拽排序）

#### 2.2 编辑器

- 富文本 / Markdown 双模式
- 自动保存（防抖 + 定时）、版本历史（可回滚）
- 字数统计、写作时长统计、每日码字目标
- 专注模式（全屏无干扰）
- 查找替换、快捷键
- 敏感词/错别字提示（可选）

#### 2.3 导出

- 导出格式：TXT / DOCX / PDF / EPUB
- 支持按卷/按章/整本导出
- 自定义导出模板（章节标题格式、分隔符）

#### 2.4 素材库

- 人物卡（姓名、外貌、性格、背景、关系）
- 设定集（世界观、地图、势力、物品、功法等）
- 大纲管理（总纲 / 卷纲 / 章纲）
- 灵感碎片记录

------

### 模块三：小说辅助模块（嵌入编辑器）

#### 3.1 AI 续写

- 基于当前上下文 + 大纲 + 人物设定，生成后续段落
- 可选风格、字数、走向（如"推进剧情/增加冲突/日常"）
- 生成结果可采纳/重写/丢弃

#### 3.2 AI 润色与改写

- 选中文本 → 润色 / 扩写 / 缩写 / 改文风 / 改视角
- 保留原意的改写建议

#### 3.3 设定一致性检查

- 检测人物名、地名、设定前后矛盾
- 检测时间线冲突
- 检测重复段落/抄袭风险（可选）

#### 3.4 智能提示

- 根据大纲提醒当前章节应完成的情节节点
- 伏笔管理：标记伏笔 → 提醒回收
- 人物出场提醒：长期未出场角色提示

#### 3.5 灵感助手

- 卡文时生成情节走向建议（3~5 个分支）
- 起名助手（人名/地名/功法名）
- 对话生成

#### 3.6 拆书联动

- 在编辑器中直接引用拆书模块的分析结果（如"参考本书节奏曲线"）
- 将拆书提取的桥段/爽点模式作为写作参考

## 三、非功能需求

| 类别     | 要求                                                         |
| :------- | :----------------------------------------------------------- |
| 性能     | 百万字小说解析 ≤ 5 分钟（异步）；编辑器输入无卡顿；章节分页加载 |
| 并发     | 初期支持 10~50 人同时在线                                    |
| 可用性   | 自动保存间隔 ≤ 30s；断网草稿本地缓存                         |
| 安全     | JWT 鉴权；作品数据用户隔离；上传文件类型/大小校验            |
| 可扩展   | AI 服务抽象为接口，可切换不同模型供应商                      |
| 兼容性   | Chrome/Edge 最新版；响应式适配 1366px 以上                   |
| 数据备份 | 每日定时备份 MySQL；版本历史保留 N 版                        |

## 四、数据库设计（核心表草案）

text

```
user            用户表
novel           作品表（user_id, title, intro, cover, status）
volume          卷表（novel_id, title, sort）
chapter         章节表（volume_id, novel_id, title, content, word_count, sort, status）
chapter_version 章节版本历史
outline         大纲表（novel_id, type: 总纲/卷纲/章纲, content, chapter_id）
character       人物卡（novel_id, name, avatar, profile_json）
setting         设定集（novel_id, category, title, content）
material        灵感/素材（novel_id, type, content, tags）
analysis_task   拆书任务（user_id, novel_id, file_url, status, progress）
analysis_chapter 章节分析结果（chapter_id, summary, emotion_score, keywords）
analysis_character 人物统计（novel_id, name, appear_count, appear_chapters）
analysis_report 分析报告（novel_id, report_json, created_at）
foreshadow      伏笔表（novel_id, content, plant_chapter_id, recover_chapter_id, status）
ai_log          AI调用日志（user_id, type, tokens, cost, created_at）
```



关键索引：`novel_id + sort`、`chapter_id`、`user_id`。

## 六、开发计划（建议分期）

### 第一期（MVP，约 4~6 周）

- 用户注册登录
- 作品/卷/章管理
- 基础富文本编辑器 + 自动保存
- TXT 上传 + 章节自动拆分
- 导出 TXT

### 第二期（核心价值，约 4~6 周）

- 拆书：章节摘要、人物统计、情节曲线
- AI 续写 / 润色
- 人物卡 / 设定集 / 大纲

### 第三期（进阶，约 4~6 周）

- 人物关系图、爽点识别、节奏分析
- 一致性检查、伏笔管理
- 导出 DOCX/EPUB/PDF
- 版本历史、写作统计

### 第四期（优化）

- 性能优化、AI 成本控制、多模型切换
- 移动端适配、协作功能（可选）

## 七、主要风险与对策

| 风险                 | 对策                                          |
| :------------------- | :-------------------------------------------- |
| 百万字 AI 分析成本高 | 分批处理 + 缓存 + 抽样分析 + 本地小模型预处理 |
| 大文件解析内存溢出   | 流式读取 + 分章入库 + 异步任务                |
| AI 输出质量不稳定    | Prompt 模板化 + 用户可调参数 + 结果可编辑     |
| 编辑器大章节卡顿     | 分页/虚拟滚动 + 分章存储                      |
| 拆书涉及版权         | 仅个人学习使用，不对外传播原文；明确用户协议  |
